# ID Card Extension / Renewal Application

## Purpose
Request renewal or extension of a university student ID card that has expired, been lost,
or needs replacement.

## Recipient
Registrar's Office / Student Affairs / ID Card Section / Security Office

## Sub-types:

### A. Expiry Extension
ID card has expired (common for students whose enrollment extends beyond initial period).
- Original ID expiry date
- Current enrollment status (still registered, final semester, etc.)
- Requested new validity period

### B. Lost / Damaged Card
- When and how it was lost or damaged
- Police report reference number (if lost — some universities require this)
- Undertaking that old card will not be misused

### C. First-Time / Delayed Issuance
Student never received their ID card.
- When they enrolled
- Whether they submitted ID card form before
- Documents available (admission letter, fee receipt, photos)

## Standard Subject Line
`Application for Student ID Card [Extension / Renewal / Replacement] — [Name] | [ID] | [Program]`

## Key Phrases
- "My student ID card (No. [XXXX]) expired on [date]..."
- "I am currently enrolled in [Program] and require a valid ID card for [campus access / library / exams]..."
- "I hereby undertake that the lost card, if found, will be returned to the university..."
- "I am enclosing [passport-size photographs / CNIC copy / fee receipt] as required..."
- "I request that a new/extended ID card be issued at the earliest..."

## Documents Typically Required
- Passport-size photographs (mention how many if known)
- Copy of CNIC / National ID
- Fee payment receipt (for replacement fee, if applicable)
- Police FIR copy (for lost card, if required by university policy)
