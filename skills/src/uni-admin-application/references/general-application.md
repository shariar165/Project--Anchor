# General / Custom Application

## Purpose
For application types not covered by specific reference files, or when the user has a
unique request to a university authority.

## When to Use This
- Semester freeze / drop
- Fee waiver / concession
- Re-admission after rustication or withdrawal
- Hostel room / accommodation request
- Transcript or document request
- Result correction or grade review
- Bonafide / character certificate request
- Any other formal student request

## Universal Approach

### Step 1 — Understand the Request
Ask: "What exactly are you requesting the university to do?"
Map it to: a permission, an approval, a correction, a document, or a waiver.

### Step 2 — Identify Recipient
| Request Type | Likely Recipient |
|---|---|
| Academic permissions | Head of Department / Dean |
| Exam-related | Controller of Examinations |
| Fee-related | Treasurer / Finance Office |
| Documents/certificates | Registrar's Office |
| Hostel | Provost / Hostel Warden |
| Disciplinary | Dean of Student Affairs |

### Step 3 — Build the Application
Use the standard format from SKILL.md. Customize:
- Subject line to match the request precisely
- Paragraph 2 to explain the specific situation
- Paragraph 3 to state the impact/urgency if relevant
- Final request to specify the exact action needed

## Semester Freeze Key Phrases
- "I wish to freeze my enrollment for [Semester, Year] due to..."
- "I intend to resume my studies from [next semester] and request that my academic record reflect this freeze..."

## Fee Waiver Key Phrases
- "Due to the financial constraints faced by my family, I am unable to pay the full fee..."
- "I humbly request a [partial / full] waiver of [fee type]..."
- "I am enclosing an income certificate / affidavit of financial status..."

## Re-admission Key Phrases
- "I wish to resume my studies after an absence of [duration]..."
- "I had to discontinue due to [reason] and have now resolved the circumstances..."
- "I request that I be re-admitted to [Program] in [Semester, Year]..."

## Result Correction Key Phrases
- "I have noticed a discrepancy in my result for [Course Name, Code]..."
- "My answer sheet/internal marks appear to have been incorrectly recorded..."
- "I request a re-checking / recounting of my marks for the said paper..."
